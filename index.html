  1. A self-hosted recipe library, meal planner and shopping list. There's no AI inside; it has an API and an MCP server instead, so the assistant you already use can drive it. Paste a recipe link, ask for five dinners, get a list sorted by aisle.

    FastAPI · MCP · SwiftUI · AGPL

    Website →GitHub →

  2. Spotify puts every podcast you follow into one feed. This splits them into playlists you define, like news for the commute or the next episode of a serial, and rebuilds them on Spotify every morning. Self-hosted, with an iOS app.

    Spotify · FastAPI · SwiftUI

    Website →GitHub →

  3. How my coffee machine joined the smart home. Part one: two Zigbee relays soldered across the power and grinder switches. Part two: a load cell in a 3D-printed dosing ring, so it grinds by weight instead of time.

    Zigbee · ESP32-C6 · 3D printed · Home Assistant

    Part one: relays →Part two: grind by weight →

  4. Seven glass lids lived in a heap in the pan cupboard and clattered every time the door shut. Now six hang on the inside of the door. The generator does it for any door: enter your door, printer bed and lids, and it renders every STL in the browser.

    PETG · OpenSCAD · WebAssembly

    Generator →Printables →

  5. An iPhone and Mac app for Vikunja, the self-hosted to-do server. Smart lists, widgets, a focus timer and offline sync. Open source.

    Swift · iOS · macOS · MIT

    App Store →Website →GitHub →

  6. One tap starts a chukka with warning bells. Game mode adds teams, handicaps and the score, and spectators can follow along in a browser.

    Swift · iPhone

    App Store →Website →

    Python · API · MIT

    API docs →GitHub →
