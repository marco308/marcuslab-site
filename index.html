YAMP

yet another meal planner. unfortunately, this one is good.

A self-hosted recipe library, meal-options planner and aisle-sorted shopping list with no LLM inside. That is the point: it ships a REST API, a first-party MCP server and a skill the server publishes about itself, so whichever AI assistant you already talk to can drive it. Paste a recipe URL, ask for five dinners, get the shopping list. Plans are pools rather than calendars, every line on the list knows which meal put it there, and the offline-first iPhone app survives a supermarket with no signal.
